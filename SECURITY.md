# Security Policy

AnonBird's goal is to provide a secure private mesh over anonymous transports. If you find a vulnerability or bug, please report it by opening an issue in this fork or by contacting the project maintainers through the repository security channel.

There is not yet an official bug bounty program for AnonBird.

## Supported Versions
- We currently support only the latest version

## Reporting a Vulnerability

Please report security issues through this fork's private vulnerability reporting flow, or open a minimal public issue that does not include exploit details if private reporting is unavailable.
